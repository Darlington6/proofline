# Solana Hackathon Project

A Solana-native project for the November 6-8, 2026 hackathon.

## Current Direction

**Product:** Proofline

Proofline is an AI-powered transaction safety layer for Solana. It helps people understand what a wallet transaction will do before they sign it, then uses Solana simulation and confirmation to show what actually happened.

The primary user is someone who is new to Solana or does not want to blindly approve wallet prompts. The first workflow will focus on SOL transfers, SPL token transfers, and a small set of common transaction patterns.

## Goals

- Build a working product that uses Solana for a meaningful core workflow.
- Prioritize a small, polished vertical slice over a broad feature list.
- Enter the AI track while remaining approachable for beginner users.
- Ship a clear demo, README, architecture notes, and submission materials before the deadline.
