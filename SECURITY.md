# Security Policy

## Scope

Proofline is a hackathon project and currently targets Solana Devnet. It is not production financial software.

Do not use mainnet funds with development builds.

## Reporting a Vulnerability

Do not open a public issue for a security-sensitive report. Contact the repository owner privately through GitHub with reproduction steps and impact.

Never include private keys, seed phrases, or other credentials in an issue or pull request.
